# Пайплайн обнаружения дефектов PatchCore

Данная папка содержит полный пайплайн для обнаружения дефектов с использованием алгоритма PatchCore.

## Описание пайплайна

Пайплайн состоит из трех основных этапов:

### Этап 1: Подготовка данных

**Вариант А: Извлечение кадров из видео**
- Используется скрипт `extract_frames.py`
- Извлекает каждый N-ный кадр из видеофайла
- Опционально: обрезка краев кадров
- Результат: набор изображений в указанной папке

**Вариант Б: Использование готового датасета**
- Структура папок как в `carpet/`:
  - `train/good/` - нормальные образцы для обучения
  - `test/` - тестовые изображения (с дефектами и без)
  - `ground_truth/` - маски дефектов (опционально)

### Этап 2: Построение Memory Bank

**Вариант А: Интерактивный режим (для видео/кадров)**
- Используется скрипт `memory_bank_builder.py`
- Позволяет вручную выбирать области изображения для включения в memory bank
- Интерактивный интерфейс с визуализацией сетки 28x28
- Результат: файл `memory_bank.pt` с выбранными патчами

**Вариант Б: Автоматический режим (для готового датасета)**
- Используется скрипт `build_memory_bank_from_train.py`
- Автоматически обрабатывает все изображения из папки `train/good/`
- Использует все патчи из нормальных образцов
- Результат: файл `memory_bank.pt`

### Этап 3: Детекция дефектов

**Вариант А: Анализ одного изображения**
- Используется скрипт `defect_viewer.py`
- Показывает тепловую карту аномалий
- Вычисляет anomaly score
- Отображает сегментационную маску дефектов

**Вариант Б: Обработка серии изображений/видео**
- Используется скрипт `defect_viewer_vid.py`
- Обрабатывает всю папку изображений
- Создает видеофайл с визуализацией дефектов
- Каждый кадр содержит: оригинал, тепловую карту, маску

## Быстрый старт

### Сценарий 1: Работа с видео

```bash
# Шаг 1: Извлечь кадры из видео
python extract_frames.py --video video.mp4 --output_dir frames --step 100

# Шаг 2: Построить memory bank интерактивно
python memory_bank_builder.py --image_dir frames --output memory_bank.pt

# Шаг 3: Проверить дефекты на одном кадре
python defect_viewer.py --image frames/frame_000100.png --memory_bank memory_bank.pt

# Или создать видео с визуализацией
python defect_viewer_vid.py --input_dir test_frames --memory_bank memory_bank.pt --output_video result.mp4
```

### Сценарий 2: Работа с готовым датасетом

```bash
# Шаг 1: Подготовить структуру папок (уже готово в carpet/)

# Шаг 2: Построить memory bank автоматически
python build_memory_bank_from_train.py --train_dir carpet/train/good --output memory_bank.pt

# Шаг 3: Проверить дефекты на тестовых изображениях
python defect_viewer.py --image carpet/test/color/000.png --memory_bank memory_bank.pt
```

### Автоматизированный пайплайн

```bash
# Запустить весь пайплайн автоматически
python run_pipeline.py --config config.json
```

## Технические детали

### Алгоритм PatchCore

1. **Извлечение признаков**: Используется предобученная ResNet-50
   - Слои: layer2 и layer3
   - Применяется Average Pooling
   - Размер feature map: 28x28

2. **Memory Bank**: База данных признаков "нормальных" патчей
   - Каждый патч представлен вектором признаков
   - Размерность зависит от архитектуры ResNet

3. **Детекция аномалий**:
   - Вычисление расстояния до ближайшего патча в memory bank
   - Метрика: Евклидово расстояние (L2)
   - Threshold: mean + 2*std

4. **Визуализация**:
   - Тепловая карта (jet colormap)
   - Бинарная маска (черно-белая)
   - Anomaly score (максимальное расстояние)

## Примечания

- Для GPU поддержки: установите CUDA-совместимую версию PyTorch
- Рекомендуемый размер изображений: 224x224 (автоматически изменяется)
- Memory bank может быть большим (зависит от количества нормальных образцов)
- Для лучших результатов используйте качественные образцы без дефектов на этапе обучения
