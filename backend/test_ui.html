Шаг 1: Калибровка image-level gate
PatchCore даёт каждому изображению anomaly score = max L2-расстояние до memory bank (сырое, до нормализации). Нормальные изображения имеют низкий score, дефектные — высокий.

Порог = процентиль scores нормальных изображений. Если score ниже порога → 0 дефектов.
p95 = 95% норм. изображений ниже порога
